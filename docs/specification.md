## 1. アプリ概要

BatriTable は、**画像をアップロードしてカード化し、最大4人でオンライン対戦できるボード／カードゲームプラットフォーム**。ブラウザだけで動作し、インストール不要・基本無料。

### コンセプト
- ユーザーが**自分だけのカードゲーム・ボードゲーム**を自由に作り、即座に友達と遊べる
- カードの**ドラッグ・回転・表裏反転・シャッフル**など、リアルに近い操作体験を提供
- ダイス・トークン・カウンターなど補助機能も搭載し、多様なゲームルールに対応

## 4. 認証システム

### 認証フロー

```
初回アクセス → 既存セッション確認
  ├─ なし → 匿名ログイン → ゲーム利用可能
  └─ あり → セッション復元 → ゲーム利用可能
                                 ↓
                          Googleログイン（任意）
                                 ↓
                          匿名→Google紐付け
                                 ↓
                          マイページ利用可能
```

| 項目 | 仕様 |
|---|---|
| **匿名ログイン** | 初回アクセス時に自動で `signInAnonymously` |
| **Googleログイン** | ロビー画面のボタンからポップアップ認証。匿名アカウントに `linkWithPopup` で紐付け |
| **永続化** | `browserLocalPersistence`（タブ跨ぎでセッション維持） |
| **ログアウト** | Google からのサインアウト → 匿名状態に戻る |
| **ID Token** | `onIdTokenChanged` で監視し、API呼び出しに使用 |
| **App Check** | reCAPTCHA v3 による不正アクセス防止 |

## 5. ルームシステム

### 5.1 ルーム作成（ホスト）

1. **ルームID** を任意入力（例: `room-abc`, `1234`）
2. **入室パスワード** を任意設定
3. **プレイヤー名** を入力（最大24文字）
4. **フィールド構成** を選択：
   - 🃏 **カードゲームモード** — プレイヤーごとに独立したエリア
   - 🎲 **ボードゲームモード** — 共有プレイエリア＋個別手札
   - 🂠 **トランプモード** — トランプカード画像を自動セットアップ
5. **入室時は全員「観戦者(Spectator)」として入室**（座席は入室後に選択・変更可能）
6. API (`/api/takeover-room`) を呼び出してルーム作成

### 5.2 ルーム参加（ゲスト）

1. ルームIDを入力
2. パスワード入力（設定されている場合）
3. プレイヤー名を入力
4. 「開始」で参加（入室時は全員「観戦者(Spectator)」）

### 5.3 ルーム管理

| **ホスト権限** | ルーム終了、他プレイヤーカード操作トグル、ルーム保存 |
| **手動終了要件** | **ホスト本人**であれば、座席の着席有無に関わらず実行可能 |
| **ハートビート** | 各座席(`heartbeatAt`)、およびホスト(`hostHeartbeatAt`)が定期更新（30〜60秒） |
| **座席タイムアウト** | `SEAT_STALE_MS = 60秒` — ハートビートが途絶えたら不在と判定 |
| **ルーム生存判定** | **いずれかの座席がアクティブ**、または**ホストが観戦者として滞在(更新)**していれば生存 |
| **ルーム自動リセット** | 全関係者の不在が60秒続いた場合、他ユーザーによる「ホスト乗っ取り」およびデータ初期化が可能 |
| **退室** | ゲストは退室ボタン、ホストはルーム終了ボタン |
| **ルーム終了** | クライアント側（または `/api/close-room`）でサブコレクション（cards/chat/seats）一括削除 |
| **パスワード認証** | SHA-256ハッシュで照合 |

### 5.4 Firestore データ構造

```
rooms/{roomId}
  ├── hostUid: string
  ├── hostSeat: number | null

  │
  ├── /seats/{1..8}
  │     ├── claimedByUid: string | null
  │     ├── displayName: string
  │     └── heartbeatAt: Timestamp
  │
  ├── /cards/{cardId}
  │     ├── imageUrl / fullUrl: string
  │     ├── owner: number (seat)
  │     ├── zone: string
  │     ├── x, y: number
  │     ├── rotation: number
  │     ├── faceDown: boolean

  │     └── ...
```

## 6. ゲームフィールド

### 6.1 カードゲームモード

各プレイヤー（SEAT1〜SEAT8）に以下のエリアが独立して配置：

| エリア | 説明 | 可視性 |
|---|---|---|
| **プレイエリア** | カードを出して勝負する領域 | 全員に表示 |
| **デッキエリア** | 山札置き場。整列・シャッフルの中心 | 全員に表示（カードは裏面可） |
| **手札エリア** | 自分だけが表を見られる領域 | 他プレイヤーには裏固定 |
| **捨て札エリア** | 不要カードの置き場 | 全員に表示 |
| **特殊エリア** | 得点・効果・保留など独自用途 | 全員に表示 |

### 6.2 ボードゲームモード

- **共有プレイエリア**（中央の大エリア）
- **各プレイヤーの手札エリア**（SEAT1〜SEAT4 ※デフォルト構成）
- **共有デッキエリア**
- **共有捨て札エリア**

### 6.3 トランプモード
- 既製のトランプカード画像（`dist/TrumpPicture/`）を自動配置
- カードゲームモードのフィールドレイアウトを使用

### 6.4 エリア詳細仕様

#### 6.4.1 カードゲームモード（およびトランプモード）
各プレイヤーの領域（`.player-area`）はCSS Gridで構成され、以下のようなレイアウトとなっている。

```text
[ PLAYER AREA (.player-area) ]
+------------------+-----------------------+------------------+
|                  |                       | DISCARD AREA     |
|                  | MAIN PLAY AREA (10fr) +------------------+
| SPECIAL AREA     |                       | DECK AREA        |
| (16.6%)          |                       |                  |
|                  +-----------------------+------------------+
| (縦方向は全域)    | HAND AREA (.hand-area)                   |
|                  | (12fr)                                   |
+------------------+------------------------------------------+
```

| エリア名 | CSSクラス | 背景色 | 横幅比 | 縦幅比 | 役割 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **特殊エリア** | `.special-area` | `#9c27b0` (紫) | **16.6%** | **100%** | カード・得点・保留など独自用途（3行貫通） |
| **メインプレイ** | `.main-play-area` | `#2d8` (緑) | **69.5%** | **66.6%** | 上部2行分を占めるメインの戦場 |
| **捨て札エリア** | `.discard-area` | `#cc6666` (赤) | **13.9%** | **33.3%** | 右側上段。使用済みカードの置き場 |
| **デッキエリア** | `.deck-area` | `#f90` (橙) | **13.9%** | **33.3%** | 右側中段。山札の置き場 |
| **手札エリア** | `.hand-area` | `#228be6` (青) | **83.4%** | **33.3%** | 下段。自分だけに表が見える手札置き場 |

> [!NOTE]
> 比率は CSS Grid の `grid-template-columns: 16.6% 10fr 2fr;` および `grid-template-rows: 1fr 1fr 1fr;` に基づいて算出されています。

- **境界線**: 各エリアの境界には `4px dashed #666` の破線が適用されている。

#### 6.4.2 ボードゲームモード
中央の広大な共有エリアをベースに、四隅に手札、中央に共有山札を配置したレイアウト。全体が **1.3倍にスケーリング** されている。

```text
+-------------------------------------------------------------+
| FIELD (#board-layout & #board-play) ※全体が 1.3倍スケール表示 |
|                                                             |
|  [HAND P1 (18x24%)]                     [HAND P2 (18x24%)]  |
|  (左上隅)                                (右上隅)            |
|                                                             |
|                                                             |
|                    SHARED CENTER BLOCK                      |
|                    (#board-center: 30% x 26%)               |
|                    +------------+------------+              |
|                    | SHARED     | SHARED     |              |
|                    | DECK       | DISCARD    |              |
|                    +------------+------------+              |
|                                                             |
|                                                             |
|  [HAND P3 (18x24%)]                     [HAND P4 (18x24%)]  |
|  (左下隅)                                (右下隅)            |
|                                                             |
+-------------------------------------------------------------+
```

| エリア名 | CSS ID/クラス | 背景色 | サイズ | 配置座標 (隅/中心) |
| :--- | :--- | :--- | :--- | :--- |
| **共有プレイエリア** | `#board-play` | `#2d8` (緑) | 100% x 100% | フィールド全域に広がる下地 |
| **手札 (SEAT1)** | `#board-hand-1` | `#228be6` (青) | 18% x 24% | 左上 (top: 2%, left: 2%) |
| **手札 (SEAT2)** | `#board-hand-2` | `#228be6` (青) | 18% x 24% | 右上 (top: 2%, right: 2%) |
| **手札 (SEAT3)** | `#board-hand-3` | `#228be6` (青) | 18% x 24% | 左下 (bottom: 2%, left: 2%) |
| **手札 (SEAT4)** | `#board-hand-4` | `#228be6` (青) | 18% x 24% | 右下 (bottom: 2%, right: 2%) |
| **中央ブロック** | `#board-center` | - | 30% x 26% | フィールド中心 (要 min-width: 260px) |
| └ **共有デッキ** | `.center-deck` | `#f90` (橙) | (50%幅) | 中央ブロック内の左側 |
| └ **共有捨て札** | `.center-discard` | `#cc6666` (赤) | (50%幅) | 中央ブロック内の右側 |

#### 6.4.3 共通・基本サイズ
- **カード基本サイズ**: `120px` x `160px`（角丸 10px）
- **プレイヤー領域 (.player-area) のサイズ**:
  フィールド設定に応じて、1名分の領域サイズ（論理ピクセル）は以下の通り決定される。

  | フィールドサイズ設定 | 横幅 (Horizontal) | 縦幅 (Vertical) |
  | :--- | :--- | :--- |
  | **小 (Small)** | 1,500 px | 850 px |
  | **中 (Medium / デフォルト)** | **2,500 px** | **1,250 px** |
  | **大 (Large)** | 5,000 px | 2,500 px |

  > [!NOTE]
  > カードゲームモードにおいて、フィールド全体が上下2段（2行）で構成されている場合の計算値です。

- **グリッド境界**: カードはエリアを跨いで移動可能。ドロップした瞬間にそのエリアの子要素として再計算される。
- **絶対配置フラグ (`isAbsolute`)**: ホストが手動で移動させたエリアは、CSS Grid の支配を離れ、座標指定による絶対配置に移行する。

## 7. カード操作

### 7.1 基本操作

| 操作 | 入力 | 説明 |
|---|---|---|
| **移動** | ドラッグ | カードをつかんで移動。エリア間の移動も可能 |
| **回転** | ダブルクリック | 90度ずつ回転 |
| **表裏反転** | 右クリック | 瞬時に表⇔裏を切り替え |
| **選択** | クリック | 赤枠表示＋右側パネルにプレビュー拡大（観戦者も可能） |
| **削除** | サイドパネルから | 全カード削除 or 指定カード削除 |
| **最背面送り** | サイドパネルから | 指定カードを最背面に移動 |

### 7.5 重なり枚数バッジ

- カードが重なった場合、最前面に赤色の枚数バッジを表示
- トークン・ダイスは枚数カウントから除外（カード同士の重なりのみカウント）

### 7.2 一括操作（サイドパネル）

| ボタン | 機能 |
|---|---|
| 🔍 全カード一覧 | 自分のカードをモーダルで一覧表示 |
| 🔍 デッキ一覧 | デッキエリアのカード一覧 |
| 🔍 捨て札一覧 | 捨て札エリアのカード一覧 |
| ↻ 全カード向きリセット | 全カードの回転をリセット |
| 🂠 全て裏に | 全カードを裏面に |
| 🂡 全て表に | 全カードを表面に |
| 🌀 デッキシャッフル | デッキ内のカード順をランダム化 |
| ❖ 全カードを集める | 全カードをデッキエリアに回収 |
| 🗑 全カード削除 | 自分の全カードを削除 |
| 🗑 指定カード削除 | 選択中のカードを削除 |
| ⬇ 指定カードを最背面 | 選択カードのz-indexを最下に |

### 7.3 画像アップロード

- `#upload-area` のタップまたはドラッグ＆ドロップで画像を追加
- 複数ファイル同時アップロード対応（`multiple` 属性）
- Firebase Storage にアップロード → Firestore にカードデータ作成

### 7.4 カード背景画像

- サイドパネルの「🖼 カード背景画像」ボタンで設定
- 裏面に表示される画像をカスタマイズ可能

## 8. 補助機能

### 8.1 ダイス＆コイン

| 機能 | 操作 |
|---|---|
| 🪙 コイントス | コインを投げて表裏をランダム表示 |
| 🎲 6面ダイス | 1〜6のランダム結果 |

### 8.2 カウンター＆トークン

| 機能 | 説明 |
|---|---|
| 🔢 数値カウンター | 汎用の数値カウンター（入力で自由に設定） |
| ➕/➖ (+1, +10, +50, +100) | 加算・減算用のカウンタートークン |
| 📝 トークン作成 | テキスト入力でトークンを生成 |
| 🖼 画像トークン作成 | 画像をアップロードしてトークンとしてフィールドに配置。高解像度対応 |

> ダブルクリックで回転、右クリックで専用コンテキストメニュー（削除・拡大・縮小・最前面/最背面移動）

#### トークン専用コンテキストメニュー（右クリック）

| 項目 | 機能 |
|---|---|
| ⬆ 最前面に移動 | トークンを他カード・トークンより手前に移動 |
| ⬇ 最背面に移動 | トークンを他カード・トークンより奥に移動 |
| 🔍 拡大 | トークンを約120%拡大（高解像度画像に自動切替） |
| 🔍 縮小 | トークンを約83%縮小 |
| ❌ 削除 | トークンを削除 |

- 拡大・縮小は `scaleLevel` で管理。同じ回数押せば元に戻る
- 画像トークンは `scaleLevel >= 1` で高解像度（`fullUrl`）に自動切替

### 8.3 プレイヤーHP

- 右パネルに**HP パネル**表示
- 各プレイヤーが自分のHP値を ＋/－ ボタンまたは直接入力で変更
- Firestore (`rooms/{roomId}/hp/p{seat}`) でリアルタイム同期
- 他プレイヤーのHPは閲覧のみ（**観戦者(Spectator)** も閲覧のみ、HP編集不可）
- 巻き戻り防止ロジック搭載（ローカル編集優先、タイムスタンプ比較）

### 8.4 チャット＆ログ

- 左サイドパネル下部にチャット＆ログ表示
- テキスト入力（最大200文字）+送信ボタン
- Firestore `rooms/{roomId}/chat/` でリアルタイム同期
- `aria-live="polite"` によるアクセシビリティ対応

### 8.5 視点操作

| 操作 | 効果 |
|---|---|
| **マウスホイール** | ズームイン/ズームアウト |
| **空ドラッグ** | 盤面パン（フィールド移動） |

- 各プレイヤー独立の視点（他人のズーム/パンに影響されない）

### 8.6 フィールドサイズ変更

- **小 / 中 / 大** の3段階

## 11. 搭載オリジナルゲーム：激・麻雀

### 概要
麻雀風の「3枚セット × 3組」で上がりを目指す対戦カードゲーム。

### カード構成（合計90枚）
- 赤 1〜9 × 3枚 = 27枚
- 青 1〜9 × 3枚 = 27枚
- 緑 1〜9 × 3枚 = 27枚
- 特殊カード 3種 × 各3枚 = 9枚

### 基本ルール
- 手札8枚からスタート
- 山札から1枚引く → 手札から1枚捨てる
- **3枚 × 3組の役**を作れたら上がり
- 役の種類：**刻子**（同じ数字3枚）または **順子**（同色連番3枚）

### 特殊アクション
- **ポン**: 他プレイヤーの捨て札 + 自分の手札で同数3枚
- **チー**: 他プレイヤーの捨て札 + 自分の手札で同色連番3枚

### カード効果（捨て札時、点数を支払って発動可能）
- スキップ、リバース、追加ドロー、捨て札回収など

## 12. ホスト専用機能

| 機能 | 説明 |
|---|---|
| **他プレイヤーカード操作** | トグルスイッチでON/OFF。ONにすると他人のカードも移動・表裏切替可能 |
| **ルームセーブ** | 現在のルーム状態（カード、HP、チャット、**各エリアのサイズ・位置**）をマイページのスロットに保存 |
| **ルームロード** | ホスト専用。保存されたスロットからルーム状態を完全に復元（現在の状態は上書き） |
| **ルーム終了** | **ホスト本人**であれば実行可能（座席の着席有無は問わない）。全データを一括削除してルームを閉鎖 |
| **エリアコンテキストメニュー** | 各エリアを右クリックして専用メニューを表示（拡大・縮小・移動・エリア追加）|

### 12.1 エリアコンテキストメニュー（ホスト専用）

各エリアをホストが右クリックすると専用メニューが表示される。

| 対象エリア | 表示される項目 |
|---|---|
| **プレイエリア** | 🔍 拡大 / 🔍 縮小 / ➕ エリア追加（デッキエリアを新規追加）|
| **デッキ・手札・捨て札エリア** | 🔍 拡大 / 🔍 縮小 / 🖐 移動 |
| **全エリア共通** | 🖼 エリア画像変更 / ❌ エリア画像削除 |

#### エリア拡大・縮小
- トークンと同様の `scaleLevel` 方式（CSS `transform: scale()` を適用）
- ホストが操作すると Firestore `rooms/{roomId}/areas/{areaId}` に同期
- 全クライアントにリアルタイム反映される

#### エリア移動
- 移動を選択すると、エリアが半透明の状態でマウスカーソルに追従する
- 他のエリアと重ならない場所でクリックすると配置確定
- 重なり検知：`intersects()` 関数で衝突判定。重なっている場合は赤くハイライトして配置不可
- 配置確定後、`isAbsolute: true` と座標・サイズが Firestore に保存される

#### デッキエリア追加
- プレイエリアのメニューから「デッキエリア」を選択すると新しい仮エリアが生成される
- フィールド内の任意の場所にドロップできる
- Firestore に `dynamic-deck-{timestamp}` 形式の一意なIDで保存される

## 13. サーバーレスAPI

### `POST /api/close-room`

ホストがルームを完全削除する。

| パラメータ | 型 | 説明 |
|---|---|---|
| `roomId` | string | 対象ルームID |
| `idToken` | string | Firebase Auth IDトークン |

**処理フロー**: トークン検証 → ホスト確認 → roomClosed フラグ → サブコレ削除 → 親doc削除

### `POST /api/takeover-room`

ルームの作成または（全員不在時の）ホスト引き継ぎ。

| パラメータ | 型 | 説明 |
|---|---|---|
| `roomId` | string | 対象ルームID |
| `idToken` | string | Firebase Auth IDトークン |

**処理フロー**: トークン検証 → ルーム存在確認 → 存在しないならルーム新規作成 / 既存なら全席不在（60秒以上経過）チェック → seats(1-8席)/cards 初期化 → hostUid 更新

### `POST /api/create-checkout-session`
Stripe 決済のチェックアウトセッションを作成（サブスクリプション）。

### `POST /api/create-portal-session`
ユーザーの Stripe カスタマーポータルセッションを作成。

### `POST /api/stripe-webhook`
Stripe からの Webhook を処理し、Firestore のユーザー権限（プレミアムステータス）を更新。

## 20. 既知の課題・改善候補

1. **`game.module.js` が巨大**（5700行超 / 218KB）— モジュール分割の余地がある
2. **`sw.js` が難読化済み**（PropellerAds関連） — 本来のPWAキャッシュ制御が不明瞭
3. **`mypage.html` 内に HTML コメントとして `//google adsense` がある**（無効なHTML）
4. **`index.html` の `<style>` 内にChatGPTとの対話テキストが残存**（L195–L203あたり）
5. **i18n が JS 内ハードコード** — 翻訳ファイル分離でメンテナンス性向上の余地
6. **Firebase 設定値** — `mypage.html` にハードコードされている（`game.module.js` はプレースホルダ方式）
7. **エリア移動後のコンテキストメニュー** — 移動されたエリアはFirestore同期後にIDが正しく付与される前提であり、タイミングによってはIDが欠落するケースがあり得る（要継続調査）
