## 1. 概要とコンセプト

### 1.1 背景と目的
BatriTableは、Webブラウザ上で物理的な卓を囲むように「自由にカードやコマを動かして遊ぶ」アナログシミュレーター基盤（Firebaseリアルタイム同期、ルーム管理、オブジェクト操作）を有しています。  
本**TRPGモード（`trpg.html`）**は、この基盤を拡張し、日本国内のTRPGオンラインセッションでデファクトスタンダードとなっている「ココフォリア（Ccfolia）」と同等の快適な操作性・演出力をWebブラウザ上で実現するとともに、**将来的な「AI（GM・NPC・リアルタイム情景生成）」の統合を前提とした次世代型バーチャルテーブルトップ（VTT）**を構築することを目的とします。

### 1.2 ココフォリアとの互換性と本システムの特徴
| 項目 | ココフォリア（Ccfolia）仕様準拠 | BatriTable TRPGモードの拡張・特色 |
|---|---|---|
| **基本盤面** | 無限キャンバス・パン・ズーム・グリッド吸着 | BatriTableの高速同期エンジンを流用した軽量・低遅延描画 |
| **コマ管理** | 立ち絵差分・ステータスゲージ・外部JSONインポート | いあきゃら等の主要キャラシートJSON取り込み完全対応 |
| **ダイス・チャット** | タブ分けチャット・BCDice構文・チャットパレット | リアルタイム演出ダイス、シークレットダイス、定型パレット |
| **演出・音響** | 背景/前景、シーン切り替え、BGM/SE同期、カットイン | プリセットシーンの一元管理、同期オーディオプレイヤー |
| **情報管理** | 共有メモ・秘匿ハンドアウト（HO） | プレイヤー個別権限付きインフォメーション管理 |
| **次世代AI連携** | なし（サードパーティ拡張依存） | **ネイティブAI搭載（AI GM、AI NPC、リアルタイム情景描写生成）** |

## 2. システム構成と導線

### 2.1 アクセス権限と入室フロー
先行開発・テスト期間中は、予期せぬ一般ユーザーの混入を防ぐため、特定アカウント（`joe9bk@gmail.com`）限定でアクセスを解放します。

1. **ロビー画面 (`lobby.html`)**:
   - `joe9bk`（`joe9bk@gmail.com`）でログインしている場合のみ、「ゲームの種類」欄の「🛠️ 開発者モード」の隣に **「🎲 TRPG」** ボタン（`#pick-mode-trpg`）を表示。
   - 一般ユーザー・匿名ログイン時は非表示。
2. **ルーム作成・参加**:
   - 「ゲームの種類」で「TRPG」を選択して「作成」をクリック。
   - ルーム作成時に `fieldMode: 'trpg'` が設定され、自動的に `trpg.html?id=[ROOM_ID]` へ遷移。
   - URL直リンクによる不正アクセス防止のため、`trpg.html` 側でも初期化時にアカウント検証ガード（非権限者はアラートを出してロビーへリダイレクト）を実行。

### 2.2 ファイル構成
```text
card-game/
├── lobby.html                  # 「🎲 TRPG」ボタン追加（joe9bk限定表示）
├── scripts/
│   └── lobby.module.js         # TRPGモード選択・入室ルーティングロジック
├── trpg.html                   # TRPG専用セッション画面（新規作成）
├── styles/
│   └── trpg.css                # TRPG専用UIスタイル（ダーク調・没入感重視）
├── scripts/
│   ├── trpg.module.js          # TRPGメインコントローラー
│   ├── trpg-board.js           # 盤面キャンバス（パン・ズーム・グリッド・コマ移動）
│   ├── trpg-chat.js            # タブチャット・BCDice連携・チャットパレット
│   ├── trpg-character.js       # キャラクター管理・ステータス・JSONインポート
│   ├── trpg-scene.js           # シーン切り替え・BGM/SE同期・カットイン
│   └── trpg-ai.js              # 将来拡張：AI GM / AI NPC連携モジュール
└── docs/
    └── trpg-specification.md   # 本仕様書
```

### 2.3 データ同期モデル（Firebase Realtime Database / Firestore）
- **`rooms/{roomId}/trpgState`**:
  - `board`: 背景画像URL、前景画像URL、グリッド設定（サイズ、表示ON/OFF、スナップON/OFF）、ズーム/座標初期値。
  - `characters`: 盤面上および待機中のキャラクターコマ一覧（座標、サイズ、ステータス、現在立ち絵、チャットパレット、オーナーUID）。
  - `markers`: 盤面に配置されたテキスト・マーカー・パネル一覧。
  - `scenes`: 登録されたシーンプリセット一覧（シーン名、背景、前景、BGM、初期配置）。
  - `notes`: 共有メモ、秘匿ハンドアウト（閲覧可能UID配列付き）。
  - `audio`: 現在再生中のBGM（URL、ループ、再生位置、音量）。
- **`rooms/{roomId}/chat`**:
  - チャット発言ログ（発言者名、アイコン、対象タブ、本文、ダイス成否メタデータ、シークレット対象UID、タイムスタンプ）。

## 3. 画面レイアウトとUI構造

画面全体は長時間のセッションでも目が疲れにくく、イラストや盤面が引き立つ**洗練されたダークテーマ（#12131a / #1a1b26 基調）**を採用。

```text
+---------------------------------------------------------------------------------------+
| [🎲 TRPG Room: room-1] [🎬 シーン切替 ▼] [🎵 BGM設定] [📝 共有メモ]       [⚙ 設定] [🚪 退室] |
+------------------------------------+--------------------------------------------------+
| [ツール]                           |                                                  |
| ↖ 選択                             |                                                  |
| ♟ コマ                             |                                                  |
| 🖼 マーカー                        |             メイン盤面ビューポート                |
| 📏 ルーラー                        |       （無限キャンバス / パン・ズーム）           |
| 👁 GM視点                          |         [キャラクターコマ・立ち絵・グリッド]      |
|                                    |                                                  |
|                                    |                                                  |
+------------------------------------+--------------------------------------------------+
|                                    | [チャット / パネル]                              |
|                                    | [メイン] [雑談] [情報] [ダイス] [AI]              |
|                                    | ------------------------------------------------ |
|                                    | ログ表示エリア（ダイス成否演出・立ち絵カットイン）|
|                                    |                                                  |
|                                    | ------------------------------------------------ |
|                                    | 発言者: [探索者A ▼] [🎨 差分 ▼]                   |
|                                    | [💬 チャット入力 / 1D100<=50               ] [送信]|
|                                    | [📋 パレット: 🎲 DEX*5 | 🎲 目星 | 🎲 正気度 ]     |
+------------------------------------+--------------------------------------------------+
```

### 3.1 メイン盤面ビューポート（Viewport）
- **キャンバス操作**:
  - 中クリック/右ボタンドラッグまたはスペースキー+ドラッグで自由パン移動。
  - マウスホイールによる滑らかな拡大・縮小（10%〜300%）。
- **グリッドシステム**:
  - 正方形マス（スクエア）および六角形マス（ヘックス）対応。
  - 1マスのピクセルサイズ調整（標準: 50px）。
  - グリッドスナップON時は、コマを離した際に最寄りのマス目中央へ自動吸着。
- **ルーラー（距離測定）**:
  - Shiftキー+ドラッグで直線を引き、マス数・移動距離を視覚的に測定。

### 3.2 トップバー（Header）
- **シーンセレクター**: ワンクリックで登録済みシーン（例: 「日常・探偵事務所」「怪異・地下道」「決戦」）へ画面背景・BGM・照明を一括切替。
- **オーディオマネージャー**: BGM・環境音・SEの音源登録、再生/停止、ループ設定、個別プレイヤー音量スライダー。
- **共有メモ / ハンドアウト**: モーダルでテキストメモ・公開HO・個別秘匿HOの編集と確認。

### 3.3 左ツールバー（Toolbox）
- **選択・移動ツール**: オブジェクトの選択、移動、回転、サイズ調整。
- **コマ追加**: キャラクター一覧からキャンバスへのドラッグ＆ドロップ配置。
- **マーカーパネル**: 盤面上に敷くマップタイル、障害物、エリア表示の配置。
- **GMマスク（黒塗り/フォグオブウォー）**: 探索前のエリアを黒いベールで覆い、GM操作で段階的に公開。

### 3.4 右ドック（チャット＆ステータスパネル）
- **マルチタブチャット**:
  - `メイン`: 進行・ダイス・ロールプレイ用。
  - `雑談`: プレイヤー同士の雑談・連絡用。
  - `情報`: GMからの情報開示、システムログ。
  - `秘匿`: 指定したプレイヤーとGMのみが見える個別ウィスパーチャット。
- **発言キャラクターセレクター**: 自身のアカウント名、参加キャラクター、ナレーション（GM）を選択。
- **立ち絵・表情選択**: 発言時や待機時の表情差分（通常、笑顔、怒り、瀕死等）をクイック選択。
- **チャットパレット**: キャラクターごとに設定された技能値・ダイスコマンド（例: `CC<=70 【目星】`）を一覧表示し、1クリックで入力欄へ転記・即時ロール。

## 4. ココフォリア準拠の機能詳細仕様

### 4.1 キャラクター駒（コマ）システム
1. **ステータス管理**:
   - 基本パラメータ（名前、フリガナ、メモ、イニシアティブ値）。
   - リソースゲージ（最大値・現在値、例: HP 12/12, MP 10/10, SAN 65/65）。
   - コマの下部にミニゲージバーをリアルタイム描画。
2. **立ち絵・差分管理**:
   - 1キャラクターに対して複数の表情差分（画像URL）を登録可能。
   - 盤面上のコマ画像およびチャット発言時のポップアップに即座に反映。
3. **外部キャラクター保管サービス連携（JSONインポート）**:
   - 「いあきゃら」「キャラクター保管所」「キャラクターアーカイブ」等からエクスポートされたJSONデータをクリップボード経由で1秒インポート。
   - 名前、HP/MP/SAN、能力値、技能値、チャットパレットが全自動で生成されるココフォリア互換仕様。

### 4.2 ダイスボット（BCDice準拠）
1. **主要ダイス構文**:
   - 汎用ダイス: `2D6`, `1D100`, `3D6+1`
   - クトゥルフ神話TRPG（第6版・第7版）: `CC<=50`, `CCB<=60`（決定的成功/スペシャル/致命的失敗の自動判定）
   - ソード・ワールド2.5: `2D6+4>=9`（成否自動判定）
   - シークレットダイス: `S1D100<=50`（GMにのみ結果を表示）
2. **ダイス演出**:
   - クリティカル（決定的成功）時は金色の光彩エフェクト、ファンブル（致命的失敗）時は深紅のクラッシュ演出。

### 4.3 スクリーン・演出システム
1. **シーンプリセット**:
   - 背景画像、前景画像、BGM、マーカー配置状態を「シーン」として保存。
   - GMがシーンをクリックすると、参加者全員の画面が一斉にフェードイン/フェードアウトで切り替わる。
2. **カットイン演出**:
   - チャットで特定のキーワード（例: `【発狂】`, `クリティカル`, `戦闘開始`）が発言された際、またはGM操作により、画面中央に大きなカットインアニメーションを表示。
3. **BGM / SE 同期プレイヤー**:
   - YouTubeオーディオまたはMP3/OGG URLに対応。
   - 全員で同時に音楽が流れ、シーン変更に伴ってBGMもクロスフェード。

## 5. 次世代機能：AI統合仕様（Roadmap）

BatriTable TRPGモードが既存のココフォリアを超える決定的な独自価値として、以下のAI統合を段階的に実装します。

### 5.1 AI GM（自律型キーパー / ストーリーテラー）
- **シナリオ解釈**: GMレス（ソロプレイまたは全員プレイヤー）で遊べるよう、シナリオテキスト（Markdown/テキスト）をAIに読み込ませる。
- **プレイヤー行動への応答**: プレイヤーがチャットで自由に入力した行動（「本棚を調べる」「店主に話しかける」）に対し、状況に応じた描写とダイス判定の要求（「図書館ロールをどうぞ」）を自動提示。
- **ダイス結果連動**: 振られたダイスの成否を受け取り、その結果に応じた描写を即座に出力。

### 5.2 AI NPC（自律対話NPC）
- 盤面上のNPCコマに「性格・設定・保有秘密・口調」をプロンプトとして設定。
- プレイヤーが「@NPC名 こんにちは」と話しかけると、そのNPCがキャラとして自然に応答。

### 5.3 AI リアルタイム情景・イラスト生成
- 探索中に予期せぬ場所（「怪しい路地裏に入ってみる」）へ行った際、AIがその場の描写プロンプトを組み立て、リアルタイムに背景画像を生成して盤面にセット。

### 5.4 AI セッションログ自動リプレイ生成
- セッション終了後、膨大なチャットログから不要なメタ発言を削ぎ落とし、読みやすい「WEB小説風リプレイ」や「要約ログ」を1クリックで自動生成して出力。

## 6. 段階的実装ロードマップ

```text
[Phase 1: 導線 & 基盤]
  ├── ロビーに joe9bk 限定の「🎲 TRPG」ボタン設置
  ├── trpg.html の新規作成と権限ガード
  └── 基本キャンバス（パン・ズーム・ダークテーマUI）の構築
        │
[Phase 2: ココフォリア互換コア]
  ├── キャラクター駒（パラメータ・立ち絵・盤面ドラッグ移動）
  ├── タブチャット & BCDice準拠ダイスボット
  └── キャラクターシートJSONインポート（いあきゃら等対応）
        │
[Phase 3: セッション演出強化]
  ├── シーン切り替え機能（背景・BGM・照明の一括同期）
  ├── 同期オーディオプレイヤー（BGM / SE）
  ├── 共有メモ & 秘匿ハンドアウト（HO）
  └── クリティカル/ファンブル演出 & カットイン
        │
[Phase 4: AI機能統合]
  ├── AI NPCチャット（自律応答キャラクター）
  ├── AI リアルタイムシーン・背景生成
  └── AI GMアシスト（シナリオ進行・描写補助・自動リプレイ作成）
```

## 7. まとめ

本仕様に基づき、まずは **Phase 1（ロビーへの限定ボタン追加、`trpg.html` の器と基本レイアウト構築）** から着手可能です。  
Firebaseの既存の通信設計を最大限に活かしながら、最高峰の没入感を持つ次世代TRPG環境を目指します。
